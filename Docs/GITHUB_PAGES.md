# GitHub Pages for Månen

The static App Store support pages live in `site/`.

Expected URLs if the GitHub repository is named `manen` and owned by `thirt33nth`:

- Landing: https://thirt33nth.github.io/manen/
- Privacy Policy: https://thirt33nth.github.io/manen/privacy/
- Support: https://thirt33nth.github.io/manen/support/

## Publish With GitHub Desktop

1. Open GitHub Desktop.
2. Add the local repository: `/Users/thirt33nth/Documents/Нейромузыка`.
3. Publish it to GitHub.
4. Recommended repository name: `manen`.
5. Push the `main` branch.
6. In GitHub, open the repository settings.
7. Go to Pages.
8. Set Source to GitHub Actions.
9. Open the Actions tab and wait for `Deploy GitHub Pages` to finish.

After the deployment finishes, use these App Store Connect fields:

- Privacy Policy URL: `https://thirt33nth.github.io/manen/privacy/`
- Support URL: `https://thirt33nth.github.io/manen/support/`

If the repository has a different name, replace `manen` in the URLs with the actual repository name.
